PRIMEROS PASOS

Scout, en tu equipo.

Empieza comprobando la instalación. Investiga desde tu terminal o conecta un agente local.

¿Solo quieres sugerir un lugar? En el mapa, elige Trabajar remoto → Agregar espacio.

1. Instala una versión verificada

Necesitas Python 3.12 o posterior. Estos comandos crean un entorno aislado. No necesitas una clave para consultar la ayuda.

Windows · PowerShell
python -m venv .venv
.venv\Scripts\python -m pip install "https://github.com/RikepilB/coworking-scout/archive/1b2cea4e988d1b9dd8ba6712b614aa74b3718e81.zip"
.venv\Scripts\Activate.ps1
scout --help
macOS y Linux
python3 -m venv .venv
.venv/bin/python -m pip install "https://github.com/RikepilB/coworking-scout/archive/1b2cea4e988d1b9dd8ba6712b614aa74b3718e81.zip"
source .venv/bin/activate
scout --help

2. Conoce el estado de tu investigación

Scout guarda los candidatos en una base local. Puedes comprobar su estado y listar las sedes; una base nueva empieza vacía.

Terminal · con el entorno activo
scout agent status --db scout.db
scout agent list --db scout.db --city Lima

3. Añade evidencia y revisa

Usa el formato de candidato para crear tu archivo con datos y fuentes reales. El ejemplo de la documentación es ficticio. Ingresar un candidato no lo publica.

Terminal · tu archivo candidate.json
scout agent ingest --db scout.db --input candidate.json

La respuesta incluye un site_id. El operador revisa sus fuentes y aprueba o rechaza el lugar con scout review. Ver el flujo de revisión →

4. Exporta los lugares aprobados

Terminal · exportación para PeruGrid
scout export-perugrid --db scout.db --city Lima --out lima-perugrid.json

El archivo queda en tu equipo. El equipo de PeruGrid lo valida e incorpora al mapa; exportar no publica automáticamente.

OTRAS FORMAS DE USARLO

Tu agente.
La misma evidencia.

Elige una interfaz según dónde se ejecuta tu herramienta.

Claude Code, Codex y OpenCode

Un agente con acceso a tu terminal puede proponer candidatos usando el CLI JSON. Mantén la aprobación en manos del operador. Estas interfaces no incluyen una conexión preconfigurada con cada cliente.

API local y OpenAPI

Inicia scout agent serve --db scout.db --port 8765 y consulta http://127.0.0.1:8765/openapi.json. La API funciona en tu equipo. ChatGPT en la nube no puede acceder a localhost; no hay conector remoto ni MCP instalado.

Resultados de Firecrawl

Scout puede transformar un archivo de extracción JSON de Firecrawl en un candidato. Firecrawl se ejecuta por separado; esta página no recibe claves ni realiza búsquedas.

scout agent firecrawl --input firecrawl-extract.json
Buscar con Google Places

scout run --city Lima usa Google Places y requiere tu propia clave, configuración y posibles cargos del proveedor. Sus datos tienen restricciones de uso y no se publican automáticamente en PeruGrid. Consulta la configuración antes de ejecutar.
